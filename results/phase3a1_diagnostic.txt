   - Every image appears exactly ONCE with label y=0 (pristine) and exactly ONCE with label y=1 (falsified).
   - An image-only classifier assigns a prediction purely based on image features V: f(V) -> {0, 1}.
   - For any image I, if f(I) = 1, it is correct for the falsified sample and wrong for the pristine sample.
     If f(I) = 0, it is correct for the pristine sample and wrong for the falsified sample.
   - In all cases, f(I) is correct for exactly 1 out of 2 instances.

     Exactly one of s(ImgB) > s(ImgA) or s(ImgA) > s(ImgB) must hold, so exactly 1 of the 2 pairs is correct in every 2-way swap.
     Hence M2 pair accuracy is also mathematically forced to be 454 / 908 = 0.5000.
